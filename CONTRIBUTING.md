# Contributing to Rubium

Спасибо за интерес к проекту! Rubium — это открытая образовательная платформа, и мы рады любой помощи.

## 📋 Code of Conduct

Проект использует лицензию Apache 2.0, и все участники обязаны соблюдать её условия. Любой вклад, представленный в проект, автоматически передаётся на условиях Apache License 2.0 (в соответствии с разделом 5 лицензии).

## 🚀 Как внести вклад

### 1. Сообщите об ошибке
- Используйте [Issues](https://github.com/your-username/rubium/issues) для сообщения об ошибках
- Опишите шаги для воспроизведения
- Приложите скриншоты или логи, если возможно

### 2. Предложите улучшение
- Создайте Issue с меткой `enhancement`
- Опишите проблему, которую решает улучшение
- Предложите пример реализации

### 3. Pull Request
1. **Fork** репозитория
2. Создайте ветку для вашей фичи: `git checkout -b feature/amazing-feature`
3. Внесите изменения
4. Закоммитьте изменения: `git commit -m 'Add amazing feature'`
5. Запушьте в ваш форк: `git push origin feature/amazing-feature`
6. Создайте Pull Request в ветку `main`
