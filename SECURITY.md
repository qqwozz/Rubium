# Политика безопасности

## Поддерживаемые версии

Rubium — активно развивающийся проект. Обновления безопасности
выпускаются только для последней стабильной версии.

| Версия  | Поддерживается     |
| ------- | ------------------ |
| latest  | :white_check_mark: |
| старые  | :x:                |

## Как сообщить об уязвимости

Если вы обнаружили уязвимость в Rubium, пожалуйста, сообщите о ней
ответственно.

**Как связаться:**

- Telegram: @KantervilleGhost, @onixxed

**Что указать в отчёте:**

- Описание уязвимости
- Шаги для воспроизведения
- Потенциальный ущерб
- Возможное решение (опционально)

**Что вы получите:**

- Подтверждение в течение 48 часов
- Оценку и ответ в течение 7 дней
- Упоминание в security advisory (если захотите)
- Мы не будем преследовать исследователей, действующих добросовестно

**Пожалуйста, НЕ:**

- Публикуйте уязвимость до её исправления
- Используйте уязвимость дальше, чем нужно для демонстрации
- Не получайте доступ, не изменяйте и не удаляйте данные пользователей

## Область применения

В зоне охвата:
- rubium.tech
- api.rubium.tech
- База данных и хранилище Supabase

Вне зоны охвата:
- Сторонние сервисы (Supabase, Cloudflare и т.д.) — сообщайте им напрямую
- Социальная инженерия
- DoS-атаки

Спасибо, что помогаете делать Rubium и его пользователей безопаснее.
